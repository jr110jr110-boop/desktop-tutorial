Issue 100, return 20, labour 50, overhead 30 => FG 140 instead of 160, false 20 variance. FIX: transferred = only credits from production receipts and earlier close-outs.
4. PoC revenue has no matching cost (GlService.Costing.cs:455-480): costs stay in WIP 10520 then FG 10503; profit overstated; loss provision loss×(1−p) only right if costs are expensed. FIX: for PoC contracts each recognition run moves cost incurred to cost of sales (Dr 701xx / Cr WIP) so margin follows progress; keep the expected-loss provision consistent (document the formula); smoke on revenue AND cost side with exact numbers.
5. Close-out stops at finished goods; no COGS per delivery (GlService.Costing.cs:320 debits 10503 with no item-cost entry; nothing reads FnWorkOrderClose on delivery). Breaks inventory reconciliation by every closed job; closed-job cost never reaches the income statement. FIX: relieve 10503 at the work order's unit cost on each CustomerDelivery (cost of sales Dr 70101-type / Cr 10503), and keep ItemCost consistent (post close-out through item cost or exclude 10503 FG from the ItemCost comparison explicitly and test both). Smoke: close job, deliver, income statement shows the cost.
