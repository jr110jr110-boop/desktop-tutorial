# ماژول تدارکات، حسابداری صنعتی و داشبورد مدیرعامل (PMIS)

وضعیت (۲۶ مهر ۱۴۰۵): بک‌اند و صفحات کامل. آزمون خودکار روی SQL Server 2022 و 2025: ۲۴۵ از ۲۴۵ قبول؛ آزمون نصب، به‌روزرسانی و بازیابی پشتیبان قبول.

## جریان تدارکات
درخواست خرید → تایید برنامه‌ریزی (و مدیرعامل از ۱۰ میلیون ریال؛ مصوبه هیئت‌مدیره از ۲۰۰ میلیون) → استعلام و پیشنهادها (۱/۲/۳ استعلام از ۱۵/۳۰/۵۰ میلیون ریال) → انتخاب برنده (دلیل اگر ارزان‌ترین نیست؛ گرید D و مسدود ممنوع؛ ارزیابی‌نشده فقط تا سقف تنخواه) → کمیته (مالی، بازرگانی، فنی از ۱۵۰ میلیون؛ مدیرعامل از ۵ میلیارد) → سفارش خرید (تهیه: بازرگانی، تایید: معاونت PMO، قرارداد کتبی از ۱۵۰ میلیون، پیش‌پرداخت تا ۲۵٪ با ضمانت‌نامه، سفارش ارزی با مدیرعامل) → ابلاغ → رسید انبار متصل به سفارش (قیمت از سفارش، رواداری مقدار ۲٪) یا تایید انجام خدمت (نه توسط خریدار) → فاکتور با تطبیق سه‌طرفه (فقط مقدار تاییدشده کیفی، رواداری قیمت ۱٪، شماره فاکتور تکراری ممنوع) → درخواست پرداخت (بازرگانی) → تایید PMO → پرداخت توسط مالی (از فاز مالی: پیش‌نویس پرداخت خزانه ← تایید ← ثبت).

همه سقف‌ها در «تنظیمات تدارکات» قابل تغییر هستند. کلید «الزام سفارش خرید» در دوره راه‌اندازی روی ۰ است؛ با ۱: رسید بدون سفارش فقط خرید تنخواه (همه ردیف‌ها با فی، جمع تا ۵۰ میلیون ریال).

ارزیابی تامین‌کننده طبق WI-PO-003: امتیاز = ΣS·W/ΣW؛ A≥85، B≥65، C≥45، D کمتر (مسدود)؛ ارزیابی مجدد هر ۶ ماه؛ سومین مرجوعی = مسدود (رفع با مدیرعامل).

## حسابداری صنعتی
میانگین موزون موجودی، هزینه مواد/پیمانکاری/خدمات به دستور ساخت و پروژه، رویدادهای حسابداری متوازن با نقش حساب، تطبیق ارزش موجودی با دفتر.
فاکتور تاییدشده: بدهکار کالای دریافتی فاکتورنشده (به قیمت سفارش) + اختلاف قیمت + ارزش افزوده / بستانکار حساب‌های پرداختنی تامین‌کننده.

## نقش‌ها
PLANNING=11، WHSUPERVISOR=12، CEO=13. تفکیک وظایف: درخواست‌کننده، تاییدکننده، خریدار، تحویل‌گیرنده و پرداخت‌کننده افراد مختلف.

## داشبورد مدیرعامل (GET api/v1/finance/ceo-dashboard، صفحه شروع مدیرعامل)
ارزش موجودی، کالای زیر حداقل، قرنطینه، درخواست/سفارش باز و دیرکرد، کالای دریافتی فاکتورنشده، بدهی تامین‌کنندگان، پرداخت‌های منتظر، تامین‌کنندگان مسدود و ارزیابی سررسید، بازرسی و NCR باز، اسناد منتظر تایید، وضعیت ارسال به سپیدار، و برای هر پروژه: مبلغ قرارداد، هزینه واقعی، تعهد سفارش‌ها و درصد هزینه به مبلغ (هشدار از ۹۰٪).

## فرم‌های چاپی (B Zar، A4، راست‌به‌چپ)
001-04-FO-WH رسید؛ 002-04-FO-WH حواله؛ FO-WH-001/002 ضایعات؛ FO-WH-020 فروش ضایعات؛ FO-QC-013 NCR؛ FO-PO-007/008/009. فرم‌های بدون کد شرکت (درخواست خرید، مقایسه، سفارش، تایید خدمت، تطبیق فاکتور، درخواست پرداخت، شمارش) با برچسب «کد توسط تضمین کیفیت تعیین شود».

## باقیمانده / منتظر کاربر
- مستندات API سپیدار (تا آن زمان خروجی فایل).
- کد فرم‌های تدارکات از تضمین کیفیت.
- تایید انبارهای پیشنهادی و ۸۵ تصمیم داده‌های موجودی اولیه.
